Cross-camera color calibration

Fit an interpretable linear-light color mapping from a reference chart and apply it to product images. No saturation/hue sliders — every number is measured and validated.

Cross-camera kit · load a reference kit and calibrate camera-to-camera

Every image in a kit is a simulated response, generated from saved parameters (kit_params.json). Pick a source chart and a target chart; the mapping is fitted on the source, then applied to the target under the target's own white balance. Patches you mark as holdout are excluded from the fit and reported as an independent check. Each row below is tied to the exact chart/scene file it came from.

Selected patches are removed from white balance, cross-validation folds, and the fit. Their residual is the independent generalization check.
